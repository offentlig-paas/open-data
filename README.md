# Offentlig PAAS open data

Anonymized survey data from Offentlig PAAS research on platforms and AI tools in the Norwegian public sector.

| Dataset | Folder |
|---|---|
| State of AI Coding Agents 2026 | [`state-of-ai-agents/2026`](state-of-ai-agents/2026) |
| State of Platforms 2024 | [`state-of-platforms/2024`](state-of-platforms/2024) |
| State of Platforms 2026 | [`state-of-platforms/2026`](state-of-platforms/2026) |

Each folder has:

- the data as CSV
  - AI agents: one row per respondent, without organization, plus tables of organization-level results
  - State of Platforms: frequency tables only
- a codebook
- the survey instrument
- a README

Survey questions and answers are in Norwegian.

Reports and articles: <https://nye.offentlig-paas.no>
