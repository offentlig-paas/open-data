# State of Platforms 2026

Survey of application platforms, Kubernetes and cloud use in Norwegian public sector organizations (Wave 2, collected Q4 2025 – Q1 2026, 48 platform entries from 45 organizations).

- `state-of-platforms-2026-aggregate.csv`: frequency table per question (aggregates only, counts below 3 suppressed)
- `CODEBOOK.md`: file format and why only aggregates are published
- `instrument.md`: the survey instrument (Norwegian, with English notes)

The table is produced by `../scripts/aggregate.py` from the non-public response file. Questions and answers are in Norwegian. Results are published at <https://nye.offentlig-paas.no>.
