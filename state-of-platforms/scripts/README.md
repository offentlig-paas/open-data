# Scripts

- `aggregate.py`: builds the published aggregate frequency tables.
- `analyze.py`: descriptive statistics per wave and paired panel tests (exact McNemar). Run `python3 analyze.py --selftest` to check the test function.

Both scripts read the response-level survey data, which is not published: respondents consented to publication of aggregated results only. The scripts document how the published numbers were computed; they cannot be run against the aggregate tables.
